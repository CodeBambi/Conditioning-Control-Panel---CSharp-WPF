# Breakout office ending

A rendered eight-second pullback from the colourful completion screen to an empty grey cubicle. No character. The camera holds on the screen for half a second, retreats until seven seconds, then holds on the desk. Authored at 24 fps; the opening camera exactly fits the 16:9 screen.

## Build
Requires Blender 5.2.1 LTS and FFmpeg. From this directory:

```powershell
& $blender --background --factory-startup --python-exit-code 1 --python build_office_polish.py
& $blender --background --factory-startup --python-exit-code 1 --python render_final.py
ffmpeg -y -framerate 24 -i final-frames/%04d.png -c:v libx264 -preset slow -crf 19 -pix_fmt yuv420p -movflags +faststart office-ending.mp4
ffmpeg -y -i final-frames/0191.png -q:v 2 office-ending.jpg
```

Set `$blender` to the local executable. `build_office_polish.py` composes the earlier construction scripts, so retain all three. The final renderer selects OPTIX or CUDA when available and falls back to CPU. It checks screen projection and packed image dependencies after reopening the blend. The scene uses metres, Cycles, AgX, exposure -0.9 and denoising. Shipping frames use 24 samples at 1280x720. `preview.png` is the inspected wide view.

The runtime assets belong in `ConditioningControlPanel/Resources/web/backroom/stations/breakout/assets/`. MP4 is already tracked with Git LFS. Generated blends, intermediate images and frame sequences stay local. Rendered outputs are not automatically copied into the app.

`assets/ending-screen.png` is the control-free end card generated by the game painter. The runtime integration PR owns `ending-card.js`; after it lands, refresh the image with `export-ending-card.mjs` and rerender. Install `@napi-rs/canvas` in a local temporary dependency directory and set `BREAKOUT_CANVAS_MODULE` to its package directory, or make it resolvable through Node. No dependency install is required to rebuild the supplied scene image.

## Validation and limits
The final blend reopened with all images packed. Its first-frame screen corners project to (0,0) and (1,1) within .001. The final still and eight sequence samples were inspected for framing, continuity and intersections. The clip is 192 frames, 8 seconds, 24 fps, 1280x720. Materials are intentionally subdued; browser/device playback still needs an owner check. The screen is static completion artwork, not recorded gameplay. AgX darkens it during the reveal; runtime includes a short restrained glitch at the transition.
