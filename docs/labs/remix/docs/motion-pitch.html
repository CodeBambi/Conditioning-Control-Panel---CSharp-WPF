PICK LIST

    Recommended set for the press-the-button flow

    • Ship Stack, Spread and Slide first. They are the three you already pointed at, and they are three different silhouettes (a pile, a grid that grows, a conveyor), so a reroll reads as a new idea rather than a new seed of the same idea.
    • Weight the pick by gif count. One gif: Mirror Tunnel or Pinwheel, the only two that carry a single file. Two to four: Stack, Spread, Cover, Swallow. Five to eight: Slide, Ripple, Ring Hop, Ken Burns Wall. Carousel only at 5 s or 8 s.
    • Weight the pick by length. A 3 s canvas suits the closed-trip layouts (Spread, Swallow, Ripple, Deal): out and back in 45 frames. The constant-drift ones (Slide, Carousel, Tunnel, Ken Burns) want 5 s or 8 s, or they hurry.
    • Reroll = new layout, then new dice. The remix code already seeds everything; add the layout id to what the code carries and the same code reproduces the same reel. A second tap on the dice inside a panel should reseed the layout only, not swap it.
    • Default to the cheap ones and let the meter decide. Order the auto-composer's first roll cheap to dear; if the size meter goes gold, reroll within the cheap set before shrinking resolution.

    Export cost

    A gif encoder pays for every pixel that changes between frames. When tile edges hold still, only the gif pixels inside them change and the palette stays stable. When rects move, every pixel in the swept area changes and resampling kills pixel repeats, so the file grows.

    Engine note

    All twelve are pure functions of (frame, tile count, frame count, orientation, seed) and return rects in canvas fractions, the shape layoutAtFrame returns today, so each is a new layout mode. The slot needs four small additions the compositor can read: alpha, rot, scale and z, plus an optional crop (centre and zoom in source space) for Ken Burns. The grid ones read their rects from the split tree, so docking and swapping keep working under them. The source clock rule stays: a gif loops to fill the canvas, and the loop marker handles a gif whose own loop does not divide the canvas length.
