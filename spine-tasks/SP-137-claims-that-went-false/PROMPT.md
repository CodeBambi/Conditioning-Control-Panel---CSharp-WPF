# SP-137 — The port tells the user something that is no longer true, and it is not the only one

## Mission

**A sentence this port shows to users went FALSE last wave, and the wave that falsified it was not
allowed to touch it.**

`client/src/CcpClient.Desktop/Features/Goon/GoonDoors.cs:105-108` tells the user, verbatim at the
merged head:

> "The residual is WebView2's own prompt: the voice screen is reachable from the title menu and its
> recorder asks the browser for the microphone directly (ui/voice/recorder.js:591), **so the browser
> can still ask you. Closing that needs a PermissionRequested-deny hook (D250).**"

SP-135 built that hook. `WebViewPermissionDeny.cs` writes `COREWEBVIEW2_PERMISSION_STATE_DENY`
through vtable slot 23 on the DTRH host, the DTRH Loom and the Goon practice host. **On the Windows
embedded path the browser can no longer ask, and the hook now exists.** On Linux the sentence is
still true: Avalonia exposes no permission API on any backend and that path returns a typed
`unsupported-platform`.

Your outcome: **the sentence becomes true on both platforms, and every sibling of its class is found
by walking rather than by memory.**

## THIS IS A CLASS, NOT AN INSTANCE, AND THE PORT ALREADY NAMED THE CLASS

`client/docs/port-lessons.md`, wave 62: **"A frozen record is not a stale sentence; a present-tense
claim is. Rot is a property of TENSE, not of age."** Records may say *"at this land the count was
thirteen"* forever. A string that asserts **"this build cannot X"** goes false silently the moment
the build can X, and nothing in this repository detects it.

**So the instance above is your entry point, not your scope.** Find every user-facing present-tense
capability claim in the port's own source and check each one against the code as it stands today.

## DERIVE THE UNIVERSE, DO NOT ACCEPT A LIST

**I am deliberately not giving you the file list.** This port has been bitten four times by a
hand-assembled universe — the haptic count that missed the default video engine, the count that
missed an already-shipped module, the FYP universe inside the document forbidding hand lists, and
SP-134's stale-token audit that dropped an entry while becoming more precise.

**Walk `client/src/CcpClient.Desktop/**` and exclude only generated bytes (`bin/`, `obj/`).** A grep
that reaches `bin/` will hand you `libvlc` DLLs and payload copies — that is noise, and it is also
the tell that the universe was not defined. **State your universe as a rule, and report its size.**

## THE HARD PART: DECIDING WHAT COUNTS AS "USER-FACING"

A doc comment that lies is a defect this port has already ruled on (SP-123: *"fixing the record while
leaving a lying doc comment in the code would invert the packet's own ruling"*). But a **doc comment**
and a **string a user reads in the app** are not the same severity, and conflating them will drown
the real finding.

**Classify, and keep the classes apart:** shown to a user, versus written for a maintainer. Fix the
first. **Report** the second with its count rather than fixing it silently, unless leaving it would
make a shipped refusal incoherent.

## THE OTHER TRAPS

### 1. Do NOT delete the caveat
**D250 is still WIP.** No browser has ever raised a permission prompt in this repository; the deny is
proved against a fake `ICoreWebView2` built in-process. **A sentence that now claims the prompt is
handled, full stop, is a NEW false claim replacing the old one.** The honest sentence states the
platform split, or names the residual headed gate, or both.

### 2. Two sentences either side stay TRUE and must survive your edit
`:102-104` — the host opens no capture device, and the shipping app grants the microphone unprompted
while this host does not, *"a TIGHTENING over upstream, not a guarantee"*. And **the CROSSING (no
peer) is still what is missing**, which is the actual reason voice notes cannot be sent. **If your
edit weakens either, you have traded one false sentence for another.**

### 3. This exact text was already corrected once, and that is why you must measure
Its wording was rewritten at the wave-65 land after a blind audit caught it claiming *"voice notes
are not in this build"* and *"opens no capture device of any kind"*. **A second improvised rewrite is
the failure mode.** Quote the current text, state which clause is false and on which platform, and
show the replacement is true **by citing the code that makes it true** — not by reading better.

### 4. A guard, or this recurs next wave
The instance exists because nothing detects the class. **If a mechanism can catch a present-tense
capability claim going false, build it and state precisely what it cannot see.** If you conclude no
honest mechanism exists at this cost, **say so and say why** — an argued refusal is a real outcome
here, and it beats a matcher over prose that over-claims its own reach. (`port-lessons.md`, wave 62:
*"the fix is never a cleverer matcher"*.)

### 5. Standing rules
No wall-clock waits — `TestWait` only. No TODOs. Every new guard watched red **at the committed
head**, with the SHA.
