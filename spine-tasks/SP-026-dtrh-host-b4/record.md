### Consults

#### Pre-approach consult (Step 1)

**Mode:** solo (council route broken — T-7). **Requested:** Fable 5. **Actual answering model:** NOT surfaced by the consult tool response (no model identity header — recorded honestly, same provenance discipline as SP-022…025).

**Verdict (decisive points folded into the design):**
1. **Snapshot/ExtensionData exclusion is a REAL trap, not a nicety** — STJ `[JsonExtensionData]` members flatten back into any serialization of the doc; the page snapshot must exclude them via a resolver modifier or an explicit snapshot shape. Implemented as an explicit snapshot map over typed members only.
