# CCP Client

Greenfield Avalonia desktop client for Windows and Linux.

## Boundaries

- All new client code, projects, tests, assets, scripts, and live planning documents belong here.
- The legacy WPF application is a read-only behavioral reference.
- The first Avalonia port under `ConditioningControlPanel/CCP.*` is read-only research.
- Port user-observable function and product intent, not old implementation architecture.
- Windows and Linux are the only target platforms.

Project scaffolding will be chosen after current Avalonia v12 research and an initial architecture review.
