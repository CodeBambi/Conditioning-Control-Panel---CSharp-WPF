## Decisions needed

- Which Linux distributions and minimum WPE/WebKit package versions are release targets?
- Does the official WebView run the unchanged WebView2-shaped `bridge.js` on Linux? If not, approve the documented minimal transport-only edit rather than native injection on each platform.
- Does one protected loopback origin with route prefixes satisfy DTRH media isolation and performance, or does measured evidence require another origin layout?
- Is WPE SHM presentation fast enough for the full DTRH scene on supported Linux hardware? If not, can the WebKitGTK dedicated-window fallback satisfy the same behavior?
- Which online source forms and sites are supported for native handoff? Direct media can be supported; browser-local `blob:`, MSE, authenticated, expiring, and DRM sources cannot be promised generically.
- Confirm that unified fullscreen video always targets every connected monitor, superseding old `DualMonitorEnabled` and `FillAllMonitorsWithVideo` limits.
- Should normal online video use the same input-capture policy as regular video, or remain passive while mandatory policy captures input?
- Which Linux distributions, display backends, and window managers define the window-behavior acceptance matrix?
- What maximum popup height fraction and AvatarTube transition/liveness bounds should become fixed acceptance constants?
- When an AvatarTube animation asset exists but cannot decode on a target, should the visible static fallback include an in-app warning or only bounded diagnostics?
- Which reviewed task-board rows form milestone 1 for `/task-auto`, and which remain explicit blockers or exclusions?
- Which advisor routes pass live probes without shared-provider rate limits, and should any council seat use a CLI backend instead of inline execution?
- Which quip/SFX events are required acknowledgements, what polyphony/latency/freshness limits apply, and what Linux PipeWire/PulseAudio ducking behavior is required?
- Should disabling local AI memory retain dormant history or delete it, are remote Ollama hosts supported, and which AI effect commands remain admissible?
- Which webcam semantic events remain in scope, what accuracy/performance budgets apply, and may deep gaze ship only after commercially usable training-data provenance is proven?
